# GotLem (GitLab Golem)

GotLem is a tool designed to identify and correct issues and epics in GitLab that do not adhere to specific management rules. It identifies problems and proposes corrections via comments containing GitLab quick actions.

## Workflow

1. **Analyze**: The tool fetches issues and epics from specified groups and projects.
2. **Evaluate**: Each item is checked against a set of rules defined in a YAML file.
3. **Report**: An interactive HTML report is generated listing all proposed corrections.
4. **Review & Execute**: You review the report in your browser, provide a Personal Access Token (PAT), and post comments directly to GitLab with one click.

## Installation

```bash
npm install
npm run build
```

## Usage

```bash
npm start -- <configPath> <reportPath>
```

- `configPath`: Path to your YAML configuration file.
- `reportPath`: Path where the HTML report will be generated (e.g., `report.html`).

## Configuration (YAML)

The tool is driven by a YAML configuration file:

```yaml
gitlab_url: "https://gitlab.com"
scope:
  groups:
    - "my-organization/core-team"
  projects:
    - "my-organization/side-project/ui-lib"
comment_prefix: "### GotLem Analysis\n"
comment_suffix: "\n\n_Auto-generated by GotLem_"
rules:
  - name: "No Milestone"
    version: 1
    perimeter: "{{#if (hasNoMilestone)}}true{{/if}}"
    comment: "This issue has no milestone. Please assign the current milestone: /milestone %\"{{getCurrentMilestone}}\""
```

### Rule Definition Fields
- `name`: Descriptive name for the rule.
- `version`: Version number (integer).
- `perimeter`: A Handlebars template expression evaluating to `"true"` if the rule applies.
- `comment`: A Handlebars template for the comment body.

### Template Functions

#### Perimeter Helpers
- `hasNoMilestone()`: Returns true if the item has no milestone assigned.
- `hasLabel(label)`: Returns true if the item has the specified label.
- Supports logical operators `and` and `or`.

#### Comment Helpers
- `getCurrentMilestone()`: Returns the title of the only open milestone for the project/group.
  - **Error Condition**: If 0 or >1 milestones are open, the helper reports an error.

## Security Note

The generated HTML report handles the GitLab Personal Access Token (PAT) entirely in your browser. The PAT is never stored, logged, or sent to any server other than the GitLab instance you specify.
